Sistema de Agendamiento de Citas

Viva Spa - Salón de Belleza

Tecnologías: HTML, CSS, JavaScript

Descripción del Proyecto

Sistema diseñado para agilizar el agendamiento de citas en el salón de belleza Viva Spa. Permite a los clientes reservar citas de forma fácil y a los administradores gestionar el calendario de turnos de manera eficiente.

Funcionalidades Principales

  • Calendario interactivo
  • Reserva de citas en tiempo real
  • Gestión de clientes
  • Panel de administración
  • Diseño responsive
